# AFK Helper

Небольшая программа с окном настроек для Linux и Windows:

- **анти-AFK** — раз в несколько минут плавно описывает мышью круг и/или проходит персонажем по кругу (W → A → S → D, клавиши и длительность настраиваются);
- **автокликер** ЛКМ и ПКМ с настраиваемым интервалом в миллисекундах;
- **бинды** — по нажатию клавиши (или комбинации) пишет команду в чат игры либо нажимает заданную последовательность клавиш;
- **автоповтор** любого бинда с интервалом в секундах;
- **пресеты** — отдельные наборы биндов для разных игр.

Всё включается и выключается горячими клавишами прямо из игры, без сворачивания.

> ⚠️ Во многих онлайн-играх анти-AFK, автокликеры и макросы запрещены правилами, а античиты могут их обнаружить. Проверьте правила своей игры — вы используете программу на свой риск.

## Возможности

| | Linux | Windows |
|---|---|---|
| Файл | `afk_helper.py` | `afk_helper_win.pyw` |
| Как работает | evdev / uinput (уровень ядра) | WinAPI: низкоуровневые хуки + SendInput |
| Внешние зависимости | `python-evdev`, `tkinter` | нет, только Python |
| X11 / Wayland | оба | — |
| Кириллица в чат | нет (только латиница) | да, в режиме печати Unicode |

Горячие клавиши по умолчанию (можно переназначить в окне программы):

| Клавиша | Действие |
|---|---|
| **F8** | вкл/выкл AFK-режима (круг мышью, ходьба, автоповтор биндов) |
| **F6** | вкл/выкл автокликера ЛКМ |
| **F7** | вкл/выкл автокликера ПКМ |

## Установка на Linux

1. Зависимости:

   ```bash
   # Debian / Ubuntu / Mint
   sudo apt install python3-evdev python3-tk
   # Arch
   sudo pacman -S python-evdev tk
   # Fedora
   sudo dnf install python3-evdev python3-tkinter
   ```

2. Доступ к устройствам ввода без root (один раз):

   ```bash
   sudo usermod -aG input $USER
   echo 'KERNEL=="uinput", GROUP="input", MODE="0660", OPTIONS+="static_node=uinput"' | sudo tee /etc/udev/rules.d/99-uinput.rules
   echo uinput | sudo tee /etc/modules-load.d/uinput.conf
   sudo modprobe uinput && sudo udevadm control --reload-rules && sudo udevadm trigger
   ```

   После этого выйдите из системы и зайдите снова. Проверка: `groups` должна содержать `input`.

   Учтите: участники группы `input` могут читать нажатия клавиатуры, это стандартная цена такого подхода.

3. Ярлык на рабочем столе и пункт в меню приложений:

   ```bash
   bash install_afk_helper.sh
   ```

   Если ярлык не запускается двойным кликом — правой кнопкой по нему → «Разрешить запуск».

   Запуск без установки: `python3 afk_helper.py`.

## Установка на Windows

1. Установите Python с [python.org](https://www.python.org/downloads/), отметив **«Add python.exe to PATH»**.
2. Запустите `afk_helper_win.pyw` двойным кликом.
3. Ярлык: правой кнопкой по файлу → «Отправить» → «Рабочий стол (создать ярлык)».

Если игра запущена от имени администратора, программу тоже нужно запускать от администратора — иначе Windows не даст ей видеть и нажимать клавиши в игре.

## Использование

### Бинды

Вкладка **«Бинды»** → кнопка **«Добавить»**. В окне бинда:

- **Клавиша запуска** — «Назначить», затем нажмите нужную клавишу или комбинацию (например, `KP5` или `Ctrl+KP5`). Работают и боковые кнопки мыши.
- **Что делать**:
  - **Написать в чат** — программа откроет чат (клавишей из настроек, по умолчанию `T`), напечатает текст и, если стоит галочка, нажмёт Enter;
  - **Нажать клавиши (без чата)** — нажимает последовательность клавиш. Её можно записать кнопкой «● Записать» (Esc — стоп) или ввести вручную через пробел:

    ```
    1 2 Q Ctrl+E SPACE WAIT:500 F1
    ```

    `WAIT:500` — дополнительная пауза 500 мс в этом месте.
- **Автоповтор каждые N сек** — бинд срабатывает сам, пока включён AFK-режим. Клавиша запуска для этого не обязательна.

Текст в чат печатается в **английской раскладке** — держите её включённой в игре (на Windows можно переключить способ печати на Unicode).

### Ходьба по кругу

На вкладке «AFK-режим» — 4 шага, у каждого своя клавиша и время удержания (по умолчанию W, A, S, D по 300 мс). Программа нажимает физические клавиши, поэтому раскладка не важна. Шаги выполняются при каждом срабатывании AFK-режима вместе с кругом мышью или вместо него.

### Автокликер

Интервал задаётся в миллисекундах отдельно для ЛКМ и ПКМ, есть случайный разброс ±%. Рекомендации:

- **от 100 мс** — надёжно и похоже на человека;
- **50–100 мс** — быстро, большинство игр засчитывают каждый клик;
- **меньше 50 мс** — игра может пропускать клики, выше риск срабатывания античита.

Пока окно программы активно, автокликер на паузе — чтобы его можно было выключить мышью.

### Пресеты

Строка «Пресет» вверху окна (над вкладками): **Новый**, **Копия**, **Переименовать**, **Удалить**. В пресете хранятся бинды и настройки чата (клавиша открытия чата, паузы, на Windows — способ печати). Круг мышью, автокликер и горячие клавиши общие для всех пресетов.

## Где хранятся настройки

- Linux: `~/.config/afk-helper/config.json`
- Windows: `%APPDATA%\afk-helper\config.json`
